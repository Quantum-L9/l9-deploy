# Archived Repository Identity

The retired repository identity was `Quantum-L9/l9-deployment-platform`.

It is not valid for OIDC repository claims, repository-scoped runner registration, approval
receipts, repository guards, deployment dispatch, release receipts, package/archive identity, or
interface-provider identity.

Historical records may retain it as provenance. Persisted external identifiers, especially the
OpenTofu remote-state namespace, may retain the short legacy token until an evidence-backed
migration is separately authorized. Retention of a storage key does not grant repository-identity
semantics.
